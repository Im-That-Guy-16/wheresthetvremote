WheresTheTVRemote

A dark widescreen theme and its companion userscript, published straight from GitLab Pages.

Stylesheet

  • WheresTheTVRemote.css

Point a userstyle manager such as Stylus, or a site stylesheet setting, at https://wheresthetvremote-75b3ea.gitlab.io/WheresTheTVRemote.css. Fonts and images are linked absolutely, so the sheet renders correctly however it is loaded.

Userscript

  • WheresTheTVRemote.user.js

Open that link with Tampermonkey or Violentmonkey installed and the manager will offer to install it. The script carries its own update URL, so new versions arrive automatically.
